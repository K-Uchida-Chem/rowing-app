# Rowing Log

ローイングの練習記録アプリ(作り直し版)。データはブラウザ内(IndexedDB)にだけ保存されます。

## 使い方

```bash
npm install       # 初回のみ
npm run dev       # 開発サーバー起動 → http://localhost:5173
npm run build     # 本番用ビルド(dist/)
npm test          # ユニットテスト(集計ロジック)
npm run lint      # リント
npm run typecheck # 型チェック(src/report の集計ロジック)
npm run dummy:json # ダミーデータをバックアップ形式で書き出す(dummy-backup.json)
```

開発サーバーの「設定」画面の最下部に、週次レポート確認用の「ダミーデータ」の入れる/消すボタンが出ます(実データには触れません)。

## 画面

- 今日: 今日の予定、コンディションスコア、練習負荷の注意、今週の数字、目標の進み具合、クイック記録、バックアップ催促
- 記録(入力できる内容):
  - 結果が未入力のインターバル(「20分×3」だけ)や、メモ・振り返りだけの記録も保存できる
  - 強度に「レース」(大会名・結果)、「さらに記録する」に 途中中止・予定・ねらい・レスト・動画URL
  - 筋トレは、セットごとの重量・回数・セット数、「その他」は種目名を入力。ラン/バイクの種類に「その他」
  - コンディションは、メモだけでも保存できる。「痛み・違和感」は、部位(腰・股関節・肩…)とつらさ(1〜5)を選べる
  - インターバルは、区間ごとの心拍(平均・最大)ときつさ(RPE)も入れられる(任意・ふだんは閉じている)
  - 「さらに記録する」に、K/P/T(良かったこと・課題・次に試すこと)・水上のクルー・目標スプリット(実績との差を表示)・指導してくれた人と助言の内容も
  - どの項目も任意。1つでも入っていれば保存できる。追加の入力欄はふだん閉じていて、通常の入力は増えない
  - 旧アプリ・Slack由来のデータ(`bike`、「10+5」の時間、距離が空の時間メニュー、種目名がメモにある筋トレなど)は、読み込み時に新アプリの形にそろえる
- 記録: エルゴ / 水上(艇種・技術的な振り返りつき。入力はエルゴと共通で、水上はワットを出さない) (単発 / インターバル。どちらも距離メニュー・時間メニューを選び、平均スプリットとレートを入力。タイム/距離とワットは自動計算) / 筋トレ / ラン・バイク(距離メニュー・時間メニュー。平均ペース、バイクは平均速度を入力し、タイム/距離は自動計算) / コンディション / 体重 / 食事。前回のメニューをワンタップで呼び出し、自己ベストなら通知
- 履歴: 日付ごと・種類ごとの一覧(絞り込み・タップで編集・削除)。日付をタップで「1日のまとめ」
- 1日のまとめ: その日の全記録と1日のメモを1画面に。Slack用の画像(PNG)保存・共有、テキストコピー
- 週次レポート(分析画面から開く): 週のサマリー(前週比つき)・体重の推移(7日移動平均。小さく簡素なグラフ)・曜日別の詳細(午前/午後、エルゴ/水上/ラン・バイク/筋トレ。エルゴ・水上は同じメニューの前回比つき)・今週の技術的な振り返りのまとめ・強度別の練習量・コンディション・今週の痛み・違和感・週の振り返りメモ(今週の振り返り/来週の課題。先週の課題を今週に表示)
- 分析: 今週のレポート(共有・コピー)、自己ベスト、週間距離(エルゴと水上)、強度ゾーン別の時間、練習負荷、2kmタイム、BIG3推定1RM、体重、ペース換算
- 設定: 週間メニュー、目標、ヘルスケア連携の手順、JSONバックアップの書き出し・取り込み
- ヘルスケア連携: iPhoneのショートカットでワークアウトと心拍をJSONにしてコピー → 「今日」画面で取り込み → 「未記入のワークアウト」から時間・距離・心拍が入った状態でメニューを記入(形式は設定画面に記載)。`#hk=`(base64url JSON)付きURLでも取り込める
- 旧アプリ(RowingAppDB)のデータは、同じブラウザで開くと初回に自動で引き継ぐ
- PWA対応(ホーム画面に追加・オフライン起動)

## 構成

- `src/recordForm.js` … 入力画面の変換(筋トレのセット行、メニューの側の判定。テストつき)
- `src/lib.js` … 記録の種類(`KINDS`)・入力項目・表示の定義。項目を増やすときはここを編集
- `src/report/` … 週次レポートの計算(`format.js` 表示の整形、`week.js` 週の境界と週の開始曜日・タイムゾーンの定数、`calc.js` 集計。画面に依存しない純粋関数でテストつき)
- `src/stats.js` … 自己ベスト・負荷・コンディションスコア・目標・週間レポートなどの計算
- `src/workouts.js` … ヘルスケアのワークアウト取り込み(JSON解析・心拍の間引き・重複防止)
- `src/db.js` … Dexie(IndexedDB)のテーブル定義とバックアップ処理
- `src/pages/` … 各画面
