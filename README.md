# Rowing Log

ローイングの練習記録アプリ(作り直し版)。データはブラウザ内(IndexedDB)にだけ保存されます。

## 使い方

```bash
npm install     # 初回のみ
npm run dev     # 開発サーバー起動 → http://localhost:5173
npm run build   # 本番用ビルド(dist/)
```

## 画面

- 今日: 今日の予定、コンディションスコア、練習負荷の注意、今週の数字、目標の進み具合、クイック記録、バックアップ催促
- 記録: エルゴ(単発/インターバル・写真読み取り) / 筋トレ / ラン・バイク / コンディション / 体重 / 食事。前回のメニューをワンタップで呼び出し、自己ベストなら通知
- 履歴: 日付ごと・種類ごとの一覧(絞り込み・タップで編集・削除)。日付をタップで「1日のまとめ」
- 1日のまとめ: その日の全記録と1日のメモを1画面に。Slack用の画像(PNG)保存・共有、テキストコピー
- 分析: 今週のレポート(AIの振り返り・共有)、自己ベスト、週間距離、強度ゾーン別の時間、練習負荷、2kmタイム、BIG3推定1RM、体重、ペース換算
- 設定: 週間メニュー、目標、Gemini APIキー、JSONバックアップの書き出し・取り込み
- 旧アプリ(RowingAppDB)のデータは、同じブラウザで開くと初回に自動で引き継ぐ
- PWA対応(ホーム画面に追加・オフライン起動)

## 構成

- `src/lib.js` … 記録の種類(`KINDS`)・入力項目・表示の定義。項目を増やすときはここを編集
- `src/stats.js` … 自己ベスト・負荷・コンディションスコア・目標・週間レポートなどの計算
- `src/ocr.js` … Gemini 呼び出し(写真読み取り・週次振り返り)
- `src/db.js` … Dexie(IndexedDB)のテーブル定義とバックアップ処理
- `src/pages/` … 各画面
